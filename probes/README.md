# probes

Одноразовые программы, каждая из которых доказывает один факт из
[research-architecture.md](../docs/research/research-architecture.md). Это не продуктовый код и не
тесты: продуктового кода ещё нет, а факт, на котором держится архитектурное решение, обязан быть
проверяемым машиной, а не памятью автора.

Каждый каталог — отдельный Go-модуль со своим `go.mod`, чтобы версии, на которых факт проверен,
были зафиксированы рядом с проверкой и не поехали вместе с зависимостями сервера.

| Проба | Что доказывает | Запуск |
|---|---|---|
| `mcp-mux/` | обе поверхности — KOMPOT и MCP — живут на одном `http.ServeMux`; SDK выводит `inputSchema`/`outputSchema` из Go-типов | `cd mcp-mux && CGO_ENABLED=0 go run .` |
| `sqlite-nocgo/` | `modernc.org/sqlite` собирается и работает при `CGO_ENABLED=0` | `cd sqlite-nocgo && CGO_ENABLED=0 go run .` |

Проба, переставшая собираться после обновления зависимости, — это не сломанная проба, а изменившийся
факт: сверьтесь с ресёрчем и поправьте там, где расхождение.
