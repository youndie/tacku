# B-37 — Экран задачи: описание, история и боковая колонка

Единственный экран макета (§3.4), которого нет. Всплыл при сборке графа: сабмит создания задачи
отвечал `navigate` на `app://task/TAC-1`, а экрана за этим адресом не существует — то есть кнопка
уводила в никуда, и молча, потому что неизвестный deeplink клиент обязан игнорировать (§12.2).
Сейчас сабмит отвечает возвратом на доску.

- **Полная история с тем же двойным авторством, что в ленте.** Формулировки для неё уже написаны —
  `render.HistoryLine`, вторая половина тех четырнадцати текстов, и до сих пор её никто не зовёт.
- **В графе этого экрана не будет, и не по забывчивости.** У маршрута `endpoint` — литеральный путь,
  параметров граф не знает; экран, адресуемый идентификатором, может быть только таким, который
  клиент умеет собрать сам (§12.1).
- **Здесь же живёт полный селектор статуса** — тот, что ушёл с карточек доски вместе с заменой на
  кнопку: «назад», «в Blocked» и «через колонку» делаются отсюда.
- Не покрывает: отказ по существу при закрытии задачи (§4.4 макета) — он появится вместе с
  операцией, которую можно отклонить.

- AC: экран отдаётся видом `form` (в нём есть комментарий и селектор), история показывает обоих
  акторов, а `HistoryLine` перестаёт быть написанным и не вызываемым.
- Anchors: `server/internal/render/copy.go`, `server/internal/httpsrv/forms.go`.
