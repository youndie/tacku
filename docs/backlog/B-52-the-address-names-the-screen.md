# B-52 — Адрес называет экран: назад, перезагрузка, ссылка

У страницы есть три вещи, которых нет у окна, и до этой задачи не работала ни одна: адрес не менялся,
«назад» уводило из продукта, перезагрузка возвращала на первый экран, а ссылку на задачу отправить
было нельзя.

## Что выбрано и почему

**History API, а не библиотека навигации.** Предлагался
[navigation3-browser](https://github.com/terrakok/navigation3-browser) — он про `androidx.navigation3`,
а здесь свой навигатор поверх kompot-диплинков, общий с десктопным прибором. Подключение означало бы
сменить модель навигации в общем коде ради браузерной истории. History API — шов на стороне wasm:
десктоп отдаёт `null` и ни одна строка этого кода там не исполняется.

**Пути, а не хеш.** Адрес выглядит адресом и его можно отправить. Цена — сервер обязан отвечать
страницей по этим путям, и он отвечает.

**Перевод, а не вторая таблица маршрутов.** `app://task/TAC-2` ⇄ `/task/TAC-2`: со схемы снимается
`app://`, больше ничего. Две таблицы разъезжаются, и тогда у человека остаётся ссылка, работающая в
одной из них. Список путей сервер берёт из того же графа, что отдаёт клиенту.

**Отвечать страницей — только по своим адресам.** Сервер, отвечающий страницей на что угодно,
превращает опечатку в пустой экран: продукт стартует и молчит. `/borad` по-прежнему 404, и это
проверено вместе с тем, что `/board` отдаёт страницу — обе стороны, обе мутации.

## Где что лежит

| | |
|---|---|
| перевод имён | `client/shared/.../Address.kt`, тест на обратимость |
| шов платформы | `History.kt` + `History.wasmJs.kt`; на JVM — `null` |
| запись позиции | `Navigator.follow` — **после** показа экрана: адрес, записанный раньше ответа, назвал бы экран, который не пришёл |
| чтение позиции | `Navigator.opening()` при старте и `startHistory()` для кнопки «назад» |
| ответ сервера | `internal/httpsrv/page.go`, список из `render.ClientPaths()` |

## Чего здесь нет

Прямой навигации «вперёд» по истории после ветвления и восстановления прокрутки — ни то, ни другое
не спрашивали, и оба стоят больше, чем дают. Записано, чтобы «не сделано» не читалось как «не
заметили».
