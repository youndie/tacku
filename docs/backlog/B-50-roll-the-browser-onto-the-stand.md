# B-50 — Выкатить браузерный клиент на стенд

[B-49](B-49-web-client.md) закрыт: страница собирается, сервер её отдаёт, вход через провайдера
проходит целиком на локальном стенде. Здесь — довести это до контура, и порядок шагов тут не
формальность.

## Что выяснилось про провайдера

Обе находки сделаны измерением живого провайдера, а не чтением документации.

**CORS нет вовсе.** `discovery` отвечает 200 без `Access-Control-Allow-Origin`, `OPTIONS` на `jwks`
и `token` — 404. Все браузерные клиенты провайдера до сих пор гоняли свою половину флоу на сервере,
поэтому запросы шли не из браузера и вопрос не вставал.

**`aud` не кладётся ни в один access-токен** — ни в браузерном флоу, ни в `client_credentials`;
`aud` есть только у `id_token`, и там это clientId. Наша проверка аудитории (§12, RFC 8707)
не может пройти ни для одного токена этого провайдера.

Из второго следует то, чего никто не знал: **агентская поверхность на стенде тоже не работала.**
Она развёрнута давно, но настоящий токен туда никто не приносил, а без обращения отказ неотличим от
исправной работы. Развёрнуто — не то же самое, что проверено.

Обе половины исправлены у провайдера — PR открыт, ссылка не приводится: этот репозиторий публичный
и соседей по имени не называет (`scripts/no_private_names.py`).

## Порядок

Порядок обязателен: с 0.2.0 формы входа в релизной сборке нет, и выкатка раньше провайдера оставит
контур без входа вовсе — а не «с частично рабочим входом».

1. Наверху вливается и **выпускается** правка провайдера; версия артефактов доезжает до его
   развёртывания, миграция применяется.
2. В провайдере заводится публичный клиент: `tacku-web`, PKCE `S256`, адрес возврата — адрес
   страницы **с завершающим `/`** (сверяется точным совпадением), аудитория — он же.
3. Существующему агентскому клиенту добавляется аудитория MCP-эндпоинта — иначе агенты продолжат
   получать токены, которые мы отвергаем.
4. `youndie/tacku` PR #2 вливается, публикуется образ (версия берётся из чарта — 0.2.0), затем
   ветка значений контура.

## Чем проверять, что доехало

Не «под поднялся» — под поднимался и раньше:

| | |
|---|---|
| CORS | `curl -D- -H 'Origin: <адрес страницы>' <issuer>/.well-known/openid-configuration` → заголовок есть |
| `aud` | получить токен и посмотреть его claims: там должен быть адрес, а не пустота |
| страница | войти человеком в браузере и увидеть доску |
| агент | сделать вызов MCP настоящим токеном — то, чего не делали ни разу |

Последняя строка важнее остальных: именно её отсутствие спрятало вторую находку.
